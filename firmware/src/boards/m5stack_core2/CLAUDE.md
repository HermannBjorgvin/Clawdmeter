# M5Stack Core2 — `m5stack_core2`

Hardware notes for this board. Shared firmware rules are in `firmware/CLAUDE.md`.

M5Stack Core2: classic ESP32 (D0WDQ6-V3), 16 MB flash, 8 MB PSRAM, the same ILI9342C 320×240 panel as the FIRE (`m5stack_fire`, the reference port) on different pins. Build env: `m5stack_core2`. USB is a UART bridge (CP2104 on v1.0, CH9102 on v1.1), so Serial is UART0 and the env must **not** set `ARDUINO_USB_CDC_ON_BOOT`.

- **Two revisions, one image.** The power chip at I2C 0x34 is an AXP192 (v1.0) or an AXP2101 (v1.1); `pmu.cpp` reads register 0x03 (0x4A = AXP2101) and drives either with raw register writes, following M5Unified / M5GFX. `info` reports `rev` as `v1.1_axp2101` or `v1.0_axp192`. Only the v1.1 has been tested on hardware.
- **The panel hangs off the power chip.** Panel power, reset and backlight are power-chip outputs, so `board_init()` must run `pmu_init()` before `display_hal_init()`: v1.1 ALDO2 is the panel reset (pulsed low), ALDO4 panel/microSD power, BLDO1 the backlight (brightness = its voltage, 2.5–3.3 V); v1.0 GPIO4 is the reset, LDO2 the panel logic, DCDC3 the backlight. The 5 V bus is on at boot: v1.1 BLDO2, v1.0 GPIO0-as-LDO plus EXTEN (as M5Unified's `setExtOutput(true)`; untested on v1.0). Arduino_GFX gets no RST pin. The microSD shares the SPI bus: its CS (GPIO 4) is held high.
- **No physical front buttons.** The FT6336U (0x38) covers the panel and a strip below it (y ≥ 240) with three printed circles. Only `touch.cpp` polls the controller (`ft6336_poll()` from `touch_hal_read()`, which LVGL calls every refresh, asleep or not; gotcha 5); `input.cpp` and `power.cpp` read the latched zone. The probe is retried once a second until the controller answers, and a held zone survives up to 5 failed reads (~75 ms) before it reads as released and splits a touch by where it *starts*: on the panel it is a screen touch, in the strip it is button A / B / C (thirds) until lifted. A → primary (Space), C → secondary (Shift+Tab), B → PWR role (tap: brightness; hold 3 s and release: pair). The side button is the power chip's own on/off switch.
- **Battery** from the power chip: the AXP2101 fuel gauge (0xA4), or an AXP192 voltage estimate. AXP2101 charging is STATUS2 (0x01) bits 6:5 == 01; bits 7:5 read 2–3 while discharging, which once showed a charging bolt on battery.
- **Speaker**: NS4168 I2S amp (BCLK 12, WS 0, DOUT 2), no codec: `chime.cpp` runs with `es8311_addr = 0` and scales the samples by `SND_VOLUME`. The amp's enable is a power-chip line (v1.1 ALDO3, v1.0 GPIO2) and stays on from boot, as M5Unified keeps it. The ding renders at 22.05 kHz (about 4–5 s on this chip at the render task's idle priority; 44.1 kHz took 10 s) and uses the soft envelope (`DING_SOFT`, `ding.h`): the small speaker turns the standard strike and click into a crack.
- MPU6886 IMU populated but unused (fixed orientation). RTC (BM8563, 0x51) unused.
